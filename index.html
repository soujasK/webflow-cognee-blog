Giving AI Agents a CMS Memory: The Webflow Connector

Webflow powers millions of marketing landing pages, technical documentation sites, and engineering blogs. When organizations build AI agents (such as automated support assistants or research copilots), they usually attempt to ingest Webflow content using web crawlers.

Crawling introduces critical failure modes: HTML boilerplate contaminates the context window, CSS class modifications churn content hashes, and deleted articles remain in vector databases forever.

Data Pipeline: Webflow to Cognee Graph
Webflow API v2 Collections & Items JSON
➔
dlt replace Engine Clean Markdown Rendering
➔
Cognee Cognify Entity & Relation Extraction
➔
Graph Memory Autonomous Agent Recall

Architectural Design

  • Document-Mode Routing: The source declares DOCUMENT_SOURCE_ATTR = "webflow", ensuring records flow through cognify natural language entity extraction rather than rigid tabular database rows.
  • Markdown Transformation: Rich HTML fields are transformed into structured markdown headers, bullet lists, and code blocks while preserving canonical URLs and slugs.
  • Automatic Forget-on-Delete: Built with write_disposition="replace". When an article is unpublished or removed upstream, it falls out of staging and Cognee's orphan_cleanup automatically purges it from the graph and vector stores.
# Usage in 4 lines:
import cognee
from cognee_community_connector_webflow import webflow_source

source = webflow_source(token="API_TOKEN", site_id="SITE_ID")
await cognee.add(source)
await cognee.cognify()
result = await cognee.search("What announcements were made in our latest product release?")

Engineering Team Brains: The Slab Wiki Connector

Slab is where fast-moving engineering teams document architecture RFCs, system runbooks, postmortems, and team onboarding guides. Without direct integration, AI coding agents and Slack bots have no visibility into why past technical decisions were made.

Data Pipeline: Slab to Cognee Graph
Slab GraphQL API Posts, Topics & Comments
➔
Markdown Enrichment Topics & Discussion Threads
➔
Cognee Cognify RFC & Decision Mapping
➔
Team Knowledge Graph Runbook & RFC Recall

Key Engineering Highlights

  • GraphQL Connection Pagination: Transparently navigates Slab's cursor-based posts(first: $first, after: $cursor) connection schema.
  • Discussion Context Capture: Ingests inline comments and author attributions alongside post content. If an engineer commented on an RFC explaining a security caveat, the AI agent remembers the caveat.
  • Topic Scoping: Allows syncing an entire company workspace or scoping by specific Topic IDs (e.g. Engineering, Security, Infrastructure).
# Ingesting Slab team documentation:
import cognee
from cognee_community_connector_slab import slab_source

source = slab_source(token="SLAB_API_KEY", topic_ids=["engineering_id"])
await cognee.add(source)
await cognee.cognify()
answer = await cognee.search("What is our disaster recovery protocol for the payments service?")

Support Without Amnesia: The Freshdesk Connector

Support teams repeatedly solve variations of the same complex customer issues. Customer support agents and automated triage bots need instant recall of past ticket resolutions and internal knowledge base solutions.

Data Pipeline: Freshdesk to Cognee Graph
Freshdesk REST v2 Tickets, Threads & Solutions
➔
Thread Normalizer Requester & Resolution Steps
➔
Cognee Cognify Support Pattern Graph
➔
Troubleshooting Recall Instant Root-Cause Matching

Key Engineering Highlights

  • Unified Support Model: Concurrently syncs public solution articles (FAQs, troubleshooting manuals) and resolved support ticket threads.
  • Conversational Thread Resolution: Parses multi-turn exchanges between customers and agents, preserving the exact steps that led to ticket resolution.
  • Polite Rate Limiting: Enforces exponential backoff and parses Retry-After headers to guarantee stable ingestion on restrictive API plans.
# Ingesting Freshdesk tickets and solutions:
import cognee
from cognee_community_connector_freshdesk import freshdesk_source

source = freshdesk_source(api_key="API_KEY", domain="mycompany.freshdesk.com")
await cognee.add(source)
await cognee.cognify()
resolution = await cognee.search("How was the Okta SAML 500 error resolved last week?")
